## 1. 一句话定位

问渠不是“一个聊天机器人”，而是**一条从课堂到数据、再从数据回到课堂的教育数据智能闭环**：

```text
学生/教师使用
   ↓
教学应用（课程、对话、练习、任务、报告）
   ↓
业务库 PostgreSQL + 事件 Kafka
   ↓
EduLake 湖仓（ODS/DWD/DWS/ADS）+ DataOps 治理
   ↓
Edumind 模型评测/训练/门禁 + RAG/语音
   ↓
更准的回答、更好的教学建议
   └──────────────→ 回到教学应用
```

## 2. 四层架构

| 层 | 名称 | 主要职责 | 典型组件 |
|---|---|---|---|
| L1 | **HodoopForge 大数据底座** | 存储、计算、消息、调度、权限 | HDFS/YARN/Hive/Spark/Flink/Kafka/Ranger/Ambari |
| L2 | **EduLake 教育数据湖 + DataOps** | 数据接入、分层建模、质量/血缘/SLO/资产/数据产品 | Iceberg、ODS/DWD/DWS/ADS、DataOps 控制台 |
| L3 | **Edumind 教育垂直大模型底座** | 基座模型、SFT/QLoRA、评测、门禁、RAG | Ollama、eduteacher、评测 rubric、Qdrant |
| L4 | **问渠智伴 AI 教育机器人应用** | 教学交付、课程建设、任务、资源、通识、双语、系统管理 | FastAPI、React、VRM、faster-whisper、edge-tts |

横向能力：身份/租户、权限、隐私、审计、可观测性、CI/CD、第三方集成。

## 3. 三类用户，三条主线

### 3.1 学生

登录 → 选课 → 教学对话（RAG + 语音）→ 练习/BKT → 学习报告 → 隐私与数据权利。

关键体验：

- 回答有教材引用；
- 掌握度跨会话保留；
- 错题、卡片、微课、讨论区可复习；
- 课堂互动、互动视频、任务提交可参与。

### 3.2 教师/教研

建课 → 章节/知识点 → 教材 RAG → 练习/任务 → 课堂互动 → 学情报告 → 资源/通识/双语。

关键能力：

- 课程门户、团队、映射、富文本、导入导出、SCORM；
- 任务扩展（作业/问卷/审批/直播/共建/报名/批阅/克隆）；
- AI 工具台（出题、教案、PPT、绘画、批阅、教学质检）；
- 课堂互动、学习支持、互动视频。

### 3.3 管理员/运维

组织/用户/自定义角色 → 配额 → 审计 → 隐私与留存 → 备份/恢复 → 发布/回滚。

关键边界：

- 业务页单校主线，多校只在系统管理出现；
- 应用层多租户已上线；数据平台湖表租户隔离仍待平台窗口；
- 等保三级是技术自检 84.8%，正式测评需第三方。

## 5. 已验证 vs 外部依赖

### 5.1 代码/运行已验证

- 课程、章节、知识点、任务、资源、通识、双语、SCORM；
- 教学对话 + RAG + 引用 + 打断/降级；
- 练习/BKT/报告/成就/闪卡/费曼/口语；
- 课堂互动、学习支持、互动视频、任务扩展；
- AI 工具台与教学质检；
- 系统管理、自定义角色、配额、审计；
- 个人信息导出/删除、留存销毁、审计哈希链；
- 等保技术自检、SCA/SBOM、备份恢复演练；
- Qixuan CI/CD、GPU ASR 镜像、依赖安全补丁。

### 5.2 必须等外部

| 项 | 责任方 |
|---|---|
| 等保三级正式测评 | 测评机构 + 组织 |
| 数据平台 Kerberos/TLS/KMS | 数据平台/基础设施 |
| 湖表租户隔离（`tenant_registry`） | 数据平台 |
| SIEM 集中留存 6 个月 | 运维 |
| 生产 TLS 证书 | 运维/CA |
| Trivy 镜像扫描、渗透/代码审计 | 安全/第三方 |
| 原生 APP/HarmonyOS | 移动端团队/商店 |
| 万人在线集群压测 | 基础设施/运维 |
| 650+ 正式课单 | 供应商 |
| 腾讯会议/Zoom 自动建会 | 企业账号/OAuth |
| 外部教务/物流协议 | 对方系统 |
